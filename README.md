# Projeto Login

Protótipo de uma tela de login responsiva, desenvolvido como exercício de construção de interfaces web. A página apresenta uma mensagem de boas-vindas e uma área de formulário para acesso a uma conta. O projeto demonstra a estrutura visual de uma tela de autenticação; não inclui, atualmente, implementação de autenticação ou backend.

## Tecnologias utilizadas

- **HTML5** — estrutura da página.
- **CSS3** — estilos e ajustes responsivos, separados em `estilos/style.css` e `estilos/media-query.css`.
- **Frameworks e bibliotecas:** não utilizados.

## Como executar localmente

Não há dependências para instalar. É necessário apenas um navegador moderno.

1. Clone o repositório:

   ```bash
   git clone https://github.com/lucasjesus00/projeto-login.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd projeto-login
   ```

3. Abra `index.html` no navegador. Alternativamente, inicie um servidor local:

   ```bash
   python -m http.server 8000
   ```

4. Acesse [http://localhost:8000](http://localhost:8000).

> **Observação:** o formulário aponta para `login.php`, mas esse arquivo/backend não faz parte do repositório. Portanto, o projeto serve para visualizar a interface e não realiza login funcional.
